Executive Summary

This repository provides a clean, fully functional reference implementation of an autonomous agent runtime in Python. Built with zero required runtime dependencies for local offline execution, it demonstrates the fundamental mechanics of modern LLM agents: think-act-observe cycles, tool registries, stateful memory persistence across invocations, and structured observability.

Orchestration Loop Core

A deterministic control loop that handles model completion, parses structured tool requests, dispatches tools via registry, captures observations, and recurses until final output.

Tool Registry Extensible

Decoupled tool interface allowing generic schema-driven execution. Includes sandboxed workspace filesystem tools and stateful memory tools.

Dual Memory System Persistent

Combines per-run in-memory working transcript memory with cross-run JSON key-value persistent storage accessed explicitly via remember and recall.

Quick Reviewer Verification

Reviewers can verify the entire test suite and deterministic demos offline in seconds:

# 1. Run full 19-test suite (0.02s)
python3 -m unittest discover -s tests -v

# 2. Run offline multi-step task & memory demo
python3 examples/multi_step_task.py

# 3. Run offline workspace TODO scanner & report demo
python3 examples/offline_todo_report_demo.py

# 4. Run offline execution trace & JSON logger demo
python3 examples/offline_trace_demo.py
