Execution Tracing & Observability

Understanding why execution tracing exists, how timing metrics work, and how JSON logs accelerate debugging.

Why Tracing Exists

Agents are non-linear state machines. Tracing reveals the exact step-by-step reasoning cycle (Model Prompt → Tool Call → Observation) without cluttering console output with raw Python dumps.

Why Timing Exists

Millisecond-level timing captures per-tool execution latency. This allows developers to instantly identify bottleneck tools, slow filesystem calls, or hanging API requests.

JSON Log Auditability

Saved JSON logs under logs/run-XXX.json create a permanent, non-sensitive audit trail of agent runs, suitable for offline analysis, regression testing, and metrics tracking.
