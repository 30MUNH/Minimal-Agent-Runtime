Reviewer Execution Guide

Complete instructions for running unit tests, offline deterministic demos, and live OpenAI agent execution.

Path A: Deterministic Offline Path (No API Key Required)

Exercising the agent runtime harness, tool dispatching, memory persistence, and tracing requires zero network access and zero third-party dependencies.

1. Run Full Unit Test Suite

python3 -m unittest discover -s tests -v

2. Run Offline Multi-Step Task Demo

python3 examples/multi_step_task.py

3. Run Offline Workspace TODO Report Generator

python3 examples/offline_todo_report_demo.py

4. Run Offline Execution Trace & JSON Logger Demo

python3 examples/offline_trace_demo.py

Path B: Live OpenAI Path (Cloud API Execution)

To run real LLM queries using OpenAI models (e.g. gpt-4.1-mini):

1. Install Optional Dependencies

python3 -m pip install -e ".[openai]"

2. Configure API Key (.env or Environment Variable)

# Option 1: Create a .env file (auto-loaded by cli.py)
echo "OPENAI_API_KEY=sk-proj-your-key" > .env

# Option 2: Export in terminal
export OPENAI_API_KEY="sk-proj-your-key"

3. Seed Reviewer Workspace & Run Task

# Seed sample files into workspace/
python3 examples/seed_workspace.py

# Execute agent task with human trace & JSON logging enabled
python3 -m agent_runtime.cli --trace --save-trace --verbose \
  "Inspect the files in the workspace, find all TODO items, create a concise report at todo-report.md, and remember where the report was saved."

4. Query Memory Across Fresh Runtime Invocations

python3 -m agent_runtime.cli "Where did you save the TODO report?"

CLI Command Line Options

Flag Type Default Description
task Positional Required Natural language task prompt for the agent.
--workspace Path workspace Directory root bounded for filesystem tools.
--memory File .agent-memory.json JSON file path for persistent cross-run memory.
--model String gpt-4.1-mini OpenAI model identifier to invoke.
--max-steps Integer 12 Maximum model-tool iterations allowed.
--trace Flag Disabled Print human-readable execution trace to console.
--verbose Flag Disabled Include full tool observation outputs in trace.
--save-trace Flag Disabled Save structured JSON log file into logs/.
